# 正则表达式

## 1. 限定符

| 字符   | 说明                                                    |
|--------|---------------------------------------------------------|
| *      | 匹配前面的子表达式零次或多次，子表达式的数量大于等于0。 |
| +      | 比*少一个匹配情况，子表达式的数量大于等于1。            |
| ?      | 匹配子表达式零次或一次。                                |
| {n}    | 精准匹配n次。                                           |
| {n,}   | 匹配子表达式大于等于n次。                               | 
| {n, m} | 匹配子表达式为n到m次。                                  |

## 2. 字符类 

| 字符   | 说明                                                                |
|--------|---------------------------------------------------------------------|
| [xxx]  | 仅匹配方括号里面列举出来的字符，如[Abc]，就只能匹配里面三个字符。   |
| [^xxx] | 仅匹配没出现在方括号里面的字符。                                    |
| [A-Z]  | 仅匹配大写字母。                                                    |
| [a-z]  | 仅匹配小写字母。                                                    |
| [0-9]  | 仅匹配数字。                                                        |
| .      | 匹配除了 \n 和 \r 两个字符，等同于[^\n\r]。                         |
| [\s\S] | 匹配所有字符，\s匹配空白符（包括换行符），\S匹配所有非空白符。      |
| \w     | 匹配字母、数字、下划线，等价于[A-Za-z0-9_]。                        |
| \W     | 与\w相反，只匹配非单词的字符，如'!'，','，'.'等无法组成单词的字符。 |
| \d     | 匹配数字，相当于[0-9]。                                             |

## 3. 非打印字符

> （1）常见的\f \n \r \t \s \S \v。  
> （2）特殊非打印字符：\cx，其中的x必须是大小写字母，\cx可以将x转化为对应的控制字符，只是Python标准库re不支持\cx这种语法。

## 4、特殊字符

| 字符 | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| $    | 从结尾开始匹配表达式。如r"world"，待匹配的字符串为"Hello world"，即可匹配成功；<br/>如果待匹配的字符串为"Hello world1"，则无法匹配成功，也就是说该正则符是用来确保最后字符串一定是表达式。                                                                                                                                                                                                                                                                                                                                                                         |
| ()   | 用于标记一个子表达式的开始位置和结束位置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| []   | 相当于Python的列表作用，可以匹配里面所列出来的字符。注意，仅可以匹配字符，比如r"[(abc),(abd)]"正则表达式中，<br/>匹配的是 ()abcd, 这七个字符，而不是'abc'和'abd'两个字符串。                                                                                                                                                                                                                                                                                                                                                                                       |
| \    | 转义字符，可以将下一个字符转化为特定符号，如\n匹配换行符，\\匹配斜杆本身，\(匹配(，使得(不再具备标记子表达式开始位置的作用。                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ^    | 有两个作用，一是从头匹配子表达式，其作用和$相反；而是在方括号内使用，表示不匹配方括号所列举的字符。                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| {}   | 标记限定符的开始和结束的位置，里面只能放数字，如{2}，{2,5}，{2,}。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| \|   | 或运算，表示两个子表达式中取其一。如r"(abc\|abd\|cfg)"正则表达式中，可以匹配到'abc'、'abd'、'cfg'这三个字符串。                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| \b   | 匹配单词边界。要理解这个正则符号的用法，就先需要了解什么是单词边界，单词边界只有两种情况，一是单词开头和结尾处都是单词，向左或者向右都没别的字符了，此时就是单词边界；<br/>二是在\w和\W之间的也是单词边界。举个例子，在r"\ba!b!c\b"的正则表达式中，指定了匹配以'a'为左单词边界以'b'为右单词边界的字符串"a!b!c"，<br/>如果在待匹配字符串"cata!b!cdog"中，由于"a!b!c"左右两边都是单词字符，'a'和'b'无法做单词边界，导致正则表达式无法匹配到字符串"cata!b!cdog"里面的"a!b!c";<br/>反之，如果待匹配字符串为"cat(a!b!c)dog"或"a!b!c abc"或"a!b!c"这种，就可以匹配到了。 |
